# Thariq

受 [Thariq 的 quadrant walk 方法](https://x.com/trq212/status/2073100352921215386) 启发的 skill 集：围绕 unknowns 的显式化展开——先烧雾、再发散、再计划、再交付、再验证。

`unknowns` 是本仓库自创的编排入口，把四象限 walk 组织成一场完整的引导对话；quadrant walk 本身来自上述文章，其余 skill 是围绕该方法的实现与延伸。

## User-invoked

- **[unknowns](./unknowns/SKILL.md)** — 按四个象限走一遍任务，把 unknowns map 交到用户手里。
- **[to-plan](./to-plan/SKILL.md)** — 写一份供审阅的实现计划：最可能变的决策置顶，机械性工作沉底。
- **[to-pitch](./to-pitch/SKILL.md)** — 打包 prototype、spec、notes 成争取 buy-in 的文档：explainer 加速理解，pitch 加速批准；用户提到 remote / 手机 / Tailscale 时，经 Tailscale 让手机直接访问。
- **[quiz-me](./quiz-me/SKILL.md)** — 就一次变更出报告和测验，满分通过才 merge。

## Model-invoked

- **[blind-spot-pass](./blind-spot-pass/SKILL.md)** — 盲点扫描：进入陌生区域前，找出并解释你的 unknown unknowns。
- **[pre-implement](./pre-implement/SKILL.md)** — 动手实现前先调用：维护 implementation notes，偏离 plan/spec 时记入 Deviations 继续。
- **[brainstorm](./brainstorm/SKILL.md)** — 在充满 unknown knowns 的领域发散：列举介入点或产出多个设计方向供用户反应。
