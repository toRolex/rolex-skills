# 提交

创建 Git commit。提交信息必须：

1. 遵循项目现有提交规范
2. 包含已完成任务及父 SPEC 引用
3. 说明关键决策
4. 说明修改的文件
5. 说明阻碍或下次迭代的注意事项

保持简洁。复用分支已有的未交付提交也属于成果，不为制造新提交而创建空实现提交。
