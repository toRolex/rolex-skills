根据当前会话完整上下文，预测用户最可能接下来提出的后续请求，最多给出 3 条具体建议。优先推荐紧接当前进展的明显下一步；建议应使用用户口吻，写成可直接提交的完整 prompt。若当前可用的 skill 或 slash command 是自然的下一步，优先按准确名称推荐，并补齐必要参数；不要编造不可用的命令。

只输出 JSON 格式的建议列表，不加解释、前言或总结：

```json
[
  {"label": "简短选项标题", "prompt": "可直接提交的完整 prompt"}
]
```

若对话已完成，或想不到有价值的下一步，返回空列表 `[]`。

用户回复某条建议对应的编号时，选择该条建议，并直接按其 prompt 继续执行。
